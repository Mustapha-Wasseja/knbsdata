# knbsdata: Discover, Retrieve and Cite Official Kenyan Statistics

An R client and standardisation layer for official data and statistical
products published by the Kenya National Bureau of Statistics (KNBS).
Provides a consistent interface for discovering surveys, publications,
aggregate indicators and geographic reference data, standardises them
into documented schemas, preserves provenance metadata such as release
dates and checksums, and generates reproducible citations. This is an
independent open-source project and is not an official KNBS product.
